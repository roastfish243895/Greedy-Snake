# 大肥鱼 · 贪吃蛇

一个零依赖、完全离线的网页贪吃蛇：一个头领着一串大肥鱼头，去吃散落在场上的 AI 图标。

双击 `index.html` 就能玩，不需要安装、不需要服务器、不联网、不发起任何网络请求。

![开局界面](previews/新版首页.png)

## 开始玩

用 Chrome 或 Edge 打开 `index.html` 即可。请保持整个文件夹完整，图片是按相对路径加载的。

- 点击「开吃」或按 Enter / 空格开始。
- 方向键 / WASD 转向；不能立即反向，最多缓存 2 次转向。
- 空格暂停，R 重来；切到其他页面会自动暂停。
- 手机上有方向按钮，也可在地图上滑动转向。
- 「铺满屏幕」进入全屏。
- 吃豆子时有一声「啵」；工具栏「音效」按钮或 M 键开关，选择会被记住。浏览器要求先有一次点击或按键，才允许出声。

## 规则与规格

| 项目 | 设置 |
| --- | --- |
| 地图 | 24×16 格，共 384 格 |
| 画布 | 1056×704，每格 44 像素（显示宽度与内在像素 1:1）；冷调近白 `#f8fafb` 与灰蓝网格 |
| 领头 | 双状态头像：接近豆子张嘴，吞下后合齿 |
| 身体 | 开局 10 个大肥鱼头像；每吞 1 颗豆子，再增加 1 个不同表情的鱼头 |
| 豆子 | 7 种 AI 图标，作为食物贴图 |
| 入场 | 从小点放大到原尺寸，460ms 缓出；新豆子出现时重复播放 |
| 边界 | 四边互通，穿墙不死 |
| 失败 | 咬到自己身体才失败；若蛇尾正好移开，允许进入那个尾格 |
| 音效 | 吃豆瞬间一声「啵」，单次采样 97.4ms 内嵌在页面里，无外部音频文件、无网络请求 |
| 占满 | 全部格子占满后结束，不会无限尝试生成食物 |

接近判定是 2 格以内（含穿墙距离）。吞下后合齿至少保持 480ms。七种豆子开局都可见，吞掉后在安全空格补一颗，种类按顺序轮换。

## 文件结构

- `index.html`：启动游戏。
- `core.js`：游戏规则（移动、穿墙、碰撞、吃豆、嘴型时序）。
- `game.js`：渲染与输入。
- `audio.js`：吃豆音效播放与音效开关。
- `style.css`：界面样式。
- `assets/head/`、`assets/fish/`、`assets/food/`：头像与食物贴图。
- `assets/sfx/pop-sample.js`：吃豆音效的单次采样（base64 内嵌 WAV）。
- `assets/manifest.json`：素材对应关系。
- `previews/`：界面与动效截图。
- `tests/`：规则测试、贴图检查、浏览器验收脚本。

吃豆音效以 base64 内嵌在 `assets/sfx/pop-sample.js` 中，而不是独立音频文件——因为 `file://` 下读取同目录音频会被 CORS 拦住，而本项目坚持「双击即玩、不装服务器」。第一次点击或按键之前不会有声音，这是浏览器的自动播放策略，不是故障。若内嵌采样解码失败，会退回程序合成的「啵」作兜底。

## 开发与验收

日常游玩不需要 Node 或 Python，它们只用于开发和验收。

```bash
node tests/core.test.cjs        # 19 项规则测试
node tests/browser.test.cjs     # 真实浏览器验收（需要 Playwright 与本机 Chrome，可用 PLAYWRIGHT_MODULE / CHROME_PATH 指定）
python tests/validate_assets.py # 贴图尺寸与透明通道检查（需要 Pillow、numpy）
```

- 19 项规则测试覆盖：四边穿越、绕行多圈、自撞（含穿墙后自撞）、吃豆增长、嘴型时序、缓出、尾格与全地图占满。
- 浏览器验收覆盖：图片加载、实际绘制、四个方向穿越、自撞重开、张嘴/合齿、吃豆与增长、键盘/触屏、滑动、手机模拟布局，以及音效开关、静音、M 键切换、偏好保留与内嵌采样解码。
- 音效用离线渲染核验，不靠耳朵：单次吃豆只出一声，起始点 9.68ms，峰值 0.300 不削波。
- 从 `file://` 打开时 0 个网页异常、0 个外部网络请求。
- 手机为浏览器模拟测试，未在实体手机或 Safari 上验证；音色未在真人听觉下确认。
